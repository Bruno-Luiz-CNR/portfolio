# Portfólio — Bruno Luiz

Portfólio pessoal com visual futurista, construído com **Next.js 16 + TypeScript** e publicado na **Vercel**.

- Fundo de partículas interativo em canvas
- Cards de projetos com filtro por categoria e modal de detalhes
- 100% estático, responsivo e com suporte a `prefers-reduced-motion`

## Rodar localmente

```bash
npm install
npm run dev
```

## Adicionar um projeto

Edite `app/projects.ts` e coloque a imagem em `public/projects/`.
